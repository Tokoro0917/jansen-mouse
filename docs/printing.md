# 3D プリントで試作する

本番の脚は 1.5 mm 厚の POM / アクリルをレーザー加工する想定です（[hardware.md](hardware.md)）。
形と動きを確かめる試作は、FDM の 3D プリンタ（PLA / PETG）でも作れます。

## STL の書き出し

```bash
cd cad
./export_print.sh        # FDM 用。穴を 0.2 mm 大きくして cad/print/ に書き出す
./export_print.sh 0      # 光造形・レーザー加工用（穴は設計どおり）
```

FDM は穴が小さめにできるので、`FDM_CLEAR` の分だけ穴を大きくしています。最初に `bar_j.stl` を 1 本刷って、
φ3 のピン（または M3 ネジ）がちょうどよく入るか確かめ、きつければ `./export_print.sh 0.3` で刷り直してください。

## 刷り方（FDM）

| 項目 | 設定 |
|---|---|
| 材料 | PLA（手で回す試作）/ PETG（モータで速く回す試験。粘りがある） |
| ノズル / 積層 | 0.4 mm / 0.15〜0.2 mm（板厚 1.5 mm を 8〜10 層） |
| 壁・充填 | 壁 3 本以上、充填 100 %（リンクは細いので、ほぼ壁だけになる） |
| 向き | 板の部品はすべて平らに置く（穴が縦になり、丸く出る） |
| 1 層目 | 「象の足」（1 層目のはみ出し）で穴が狭くなるので、スライサーの補正を入れるか、φ3.2 のドリルでさらう |
| 反り | 板が薄いので、ブリムを付けるか、ベッドをきれいにする |

板の部品はどれも厚さ 1.5 mm なので、1 台分（リンク 72 個 + ウェブ 12 枚 + フレーム 8 枚）を数回に分けて並べて刷れます。

## ピン・スペーサ・ネジ

関節は φ3 のピンで、部品の間に 0.3 mm のワッシャを挟みます。関節ごとのピンの長さ・途中を埋めるスリーブ・
ワッシャ・E リングの数は [parts_list.md](parts_list.md) にまとめています（寸法から自動生成）。

**注意**: 1 モジュールの 11 本のピンのうち 6 本（B・B'・D・D'・E・E'）は、片方の端のすぐ外側の層を別の部品が通ります。
その端は E リングも付けられず、ピンも出っ張らせられないので、**ピンの先を端の部品の面に揃えて接着**します（[parts_list.md](parts_list.md) の「端」の列）。
そのため **M3 ネジ + ナットで代用できるのは、両端に余裕のある C・C'・F・F' だけ**です。ほかは φ3 の丸棒を使ってください
（ステンレスの丸棒をニッパー / 金のこで切り、端をやすりで整える）。

## 試作の順番

1. **脚 1 本**: `layout.stl` 1 枚 + `frame.stl` 1 枚 + `web.stl` 1 枚。フレーム板にウェブと脚を組み、ウェブを手で回して、
   足先が平らな軌跡を描くか、引っかかる所がないかを見る。
2. **1 モジュール（前後 2 本）**: 脚 2 本分 + フレーム板 2 枚 + ウェブ 2 枚。積層の順番どおりに重ね、
   前後の脚がぶつからずに回るかを見る。
3. **片側（3 モジュール = 6 本）**: + 六角シャフトで 3 組のウェブを 120° ずつずらしてつなぐ。モータを付け、
   **速度を上げていって、500 mm/s（クランク毎秒 9 回転）で歩けるか**を確かめる（[design.md](design.md#63-モータの選定)）。
   シミュレーションに入っていない脚の慣性・足の跳ね・滑りは、ここで初めて分かる。
4. **全体**: 左右 2 組 + ブリッジ + モータ押さえ + 基板。

## 注意

- 3D プリントの PLA は、POM より摩擦が大きく、穴がすり減りやすいです。手で回す試作には十分ですが、
  速く長く回すとピン穴が広がります。本番はレーザー加工の POM を想定しています。
- 板厚を 1.5 mm より厚くすると、12 本の脚が通路の中で旋回できなくなります（[design.md](design.md#23-縮尺脚の本数板厚の決め方)）。
  試作で厚くする場合は、旋回の確認はできません。
- 壁センサのホルダは光を通さないことが大事です。FDM で刷るなら黒の材料で、壁を厚めにしてください。
