## 機体構成

```
        前
   ┌─────────────┐
   │ 左脚群 │電装│ 右脚群 │   左右それぞれ:
   │ 6 脚   │部  │ 6 脚   │   側板 ×2 の間に 3 スロー・クランク
   │ (M_L)  │    │ (M_R)  │   各スローに前向き脚 + 後ろ向き脚（鏡像）
   └─────────────┘
        後
```

- 各側のクランク軸は 1 本。3 枚のクランク円板（`crank()`）を 120° ずつずらして固定。
- 側板（`frame()`）にクランク軸受 O と、前後の脚の固定点 B / B' を持たせる。
- 電装部は左右の側板の間。壁センサ基板は下へ吊り下げて地上 25〜35 mm に配置。

## 組み立て・調整手順

1. `cad/parts.scad` で部品を出力（`PART` を切り替え）。脚 1 本あたり: バー j, k, c, f 各 1、上三角形 1、足三角形 1。
2. 関節はガタが少なく、かつ軽く回ることを優先。組み立て後、手でクランクを回して全姿勢で引っ掛かりがないか確認。
3. モード 0 で以下を確認・設定（`firmware/include/config.h`）:
   - 前進方向にクランクを手で回して、左右のエンコーダが**増える**こと（逆なら `kMotorLSign / kMotorRSign`）。
   - 機体を左に回すとヨー角が**増える**こと。
   - 区画中央に置いたときの左右センサ値 → `kSideRefL / kSideRefR`。
   - 前壁ありで中央に置いたときの FL+FR → `kFrontRefSum`。
   - 壁あり / なしの中間値 → `kWallThrFront / kWallThrSide`。
4. モード 3 でストライド較正: 5 区画（900 mm）を歩かせ、実際の移動距離を測る。
   `kStrideCorrection *= 実測 / 900` とする。
5. 1 区画直進・90° 旋回を繰り返して PID を調整してから、モード 1 で探索。
